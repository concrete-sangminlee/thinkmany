## 이 책은 무엇인가

박사 과정의 5-7년은 인생에서 가장 밀도 높고도 불확실한 시간이다. 무엇을 배워야 하는지, 무엇을 피해야 하는지, 어떻게 지도교수와 소통하고, 언제 논문을 내고, 어떻게 멘탈을 지키는지 같은 핵심은 대개 명시적으로 가르쳐지지 않는다. 이 책은 그 시행착오를 각자 뒤늦게 배우지 않도록, 박사 과정의 실제 의사결정 지도를 먼저 펼쳐 놓는다.

- **한국 공학 대학원 현실을 정면으로 다룬다.** 위계, 회식, 학연, 병역, BK21, 과제 중심 운영처럼 실제로 부딪히는 문제를 피하지 않는다.
- **추상적 조언보다 결정 프레임을 준다.** 단계, 체크리스트, 비교표, 대응 원칙으로 바로 판단할 수 있게 구성했다.
- **AI 시대의 박사 과정을 반영한다.** ChatGPT, Claude, Copilot을 어떻게 도구로 쓰고 어디서 선을 그을지까지 다룬다.
- **박사 전후를 한 흐름으로 묶는다.** 입학 전 준비부터 박사 후 첫 1년, 그 이후의 학습 자세까지 이어진다.

## 사이트

정적 웹북이다. `npm run build`가 장마다 미리 렌더링한 HTML을 `_site/`에 만들고, GitHub Actions가 그것을 GitHub Pages에 올린다.

- **장마다 고유한 주소**: `/thinkmany/ch05/`, 섹션은 `/thinkmany/ch05/#섹션-이름`. 장마다 제목, 설명, canonical, Open Graph, 구조화 데이터가 따로 있어 검색엔진과 메신저 미리보기에 장 단위로 보인다. 예전 `#ch05` 링크는 새 주소로 넘어간다.
- **빠른 첫 화면**: 본문이 HTML에 이미 들어 있어 스크립트를 기다리지 않고 보인다. 탭, 표, 코드 복사 같은 본문 기능은 목차 색인을 기다리지 않고 바로 동작하고, 마크다운 해석기는 첫 화면에서 받지 않는다(다른 장으로 이동할 때 쓰도록 한가할 때 미리 받는다). 이후 이동은 History API로 그 자리에서 바꾸고, 뒤로 가기 하면 읽던 위치로 돌아간다. JavaScript가 꺼져 있어도 본문은 읽힌다.
- **장 사이 링크**: 본문에서 `ch05`처럼 다른 장을 언급하면 그 장으로 가는 링크가 된다 (860여 곳). 장 끝의 "연결된 장"에는 이 장이 언급한 장과 이 장을 언급한 장이 모인다.
- **장별 공유 카드**: 장마다 제목이 들어간 미리보기 이미지(`assets/og/chNN.jpg`)가 있어, 장 링크를 공유하면 그 장의 카드가 뜬다.
- **검색**: `/` 또는 `Ctrl K`. 장·섹션 제목은 즉시, 본문 전체는 Web Worker가 백그라운드에서 색인해 찾는다. 결과를 열면 해당 위치로 이동해 검색어를 강조한다. 장·섹션 제목은 초성으로도 찾는다(`ㄴㅁ`, `논ㅁ` → 논문).
- **이어 읽기**: 장마다 읽은 위치와 진행률을 기억하고, 다 읽은 장은 목차에 표시한다. 북마크, 체크리스트 상태도 브라우저에 저장된다.
- **읽기 기록 옮기기**: 설정 메뉴에서 기록을 링크로 보내거나 파일로 저장한다. 다른 기기에서 링크를 열거나 파일을 불러오면, 무엇을 가져오는지 보여 준 뒤 그 기기의 기록과 합친다(지워지는 기록은 없다). 서버에는 아무것도 저장하지 않는다.
- **최근 보강**: git 기록에서 장마다 마지막으로 보강한 날을 읽어 장 머리말과 홈의 "최근 보강된 장"에 보여 준다. 최근 보강 30건은 Atom 피드(`/thinkmany/feed.xml`)로도 구독할 수 있다. 서식만 바꾼 커밋은 `.git-blame-ignore-revs`에 적어 두면 보강으로 세지 않는다.
- **읽기 설정**: 글자 크기 4단계(`+`/`-`), 밝은·어두운 테마(`D`, 기본은 시스템 설정), 남은 읽기 시간 표시, 현재 장만 깔끔하게 인쇄.
- **접근성**: axe-core 기준(WCAG 2.1 AA) 위반 없음을 목표로 한다. 글자 대비 4.5:1 이상, 키보드로 모든 기능 사용, 검색 결과는 listbox/option 구조.
- **수식**: `$…$`, `$$…$$`를 KaTeX로 렌더링한다(수식이 있는 장에서만 불러옴).
- **오프라인**: Service Worker가 앱 셸과 한 번 연 장을 캐시한다.
- **키보드**: `J`/`K` 섹션 이동, `[`/`]` 장 이동, `B` 북마크, `T` 목차, `?` 도움말. 한글 입력 상태에서도 동작한다.

```
content/chNN-*.md       본문
content/config.json     파트·장 구성, 읽기 경로, siteUrl (관리자 페이지에서 편집)
templates/              페이지 틀 (page.html), 404, 공유 카드 원본
js/views.js             홈·장·목차 화면 템플릿. 빌드와 브라우저가 함께 쓴다
js/lib/markdown.js      마크다운 파이프라인 (헤딩 id, 수식, 장 링크, 분량 계산)
js/app.js               라우터, 하이드레이션, 진행률, 단축키
js/search.js            검색 대화상자 (+ js/search-worker.js 본문 색인)
js/enhance.js           본문 후처리 (탭, 표, 코드 복사, 수식, 체크리스트)
js/render.js            앱 안에서 장을 열 때만 불러오는 마크다운 렌더러
js/vendor/              marked 18.1.1, DOMPurify 3.4.17 (버전 고정)
scripts/build.mjs       검증 + _site/ 생성
scripts/serve.mjs       로컬 미리보기 서버 (변경 시 다시 빌드)
tests/                  node --test 단위·빌드 테스트
admin/                  GitHub API로 본문과 목차를 고치는 관리자 페이지
```

### 로컬에서 보기

Node 22 이상이 필요하다. 설치할 패키지는 없다.

```bash
npm run dev
```

그다음 http://localhost:8000/thinkmany/ 를 연다. 파일을 고치면 자동으로 다시 빌드된다.

### 글을 고칠 때

1. `content/chNN-*.md`를 고친다(또는 `/admin`에서 편집). 장을 더하거나 순서를 바꾸려면 `content/config.json`을 고친다.
2. `npm run check`로 검증한다. 다음 경우에 실패한다.
   - 목차와 파일이 어긋나거나, 장 id가 사이트 폴더 이름과 겹칠 때
   - 긴 줄표(em dash, en dash)가 있을 때. 쉼표, 콜론, 괄호를 쓴다.
   - 제목 단계를 건너뛸 때(`##` 다음 `####`). 장 제목이 h1이므로 본문은 `##`부터 쓴다.
   - 본문 HTML에 `<h1>`~`<h6>`를 쓸 때. 카드, Do/Don't, 탭 안의 제목은 문서의 절이 아니라 이름표이므로 `<div class="card-title">`, `<p class="do-dont-title">`, `<p class="tab-title">`을 쓴다.

   `<div>` 짝이 맞지 않으면 경고만 한다.

   글은 그대로 두고 서식만 일괄로 바꾼 커밋이라면, 커밋 해시를 `.git-blame-ignore-revs`에 더한다. 그러면 그 커밋은 "보강" 날짜와 피드에 잡히지 않는다.
3. `npm test`로 테스트를 돌린다.
4. `main`에 푸시하면 GitHub Actions가 테스트, 빌드, 배포를 한다. PR에서는 테스트와 빌드만 한다.

본문에서 쓸 수 있는 블록: `highlight-box` (`tip` · `info` · `warning` · `important` · `highlight-important`), `card-grid`/`card`, `pipeline`, `timeline`, `tab-container`, `do-dont`, `check-list`, 그리고 표·코드·수식. 다른 장은 `ch05`처럼 id만 쓰면 링크가 된다.

공유 카드(`assets/og-image.png`, 장별 `assets/og/chNN.jpg`)와 아이콘은 `npm run images`로 다시 만든다(Playwright 필요). 장 제목을 바꾸거나 장을 더했을 때 돌리면 되고, 카드가 없는 장은 기본 카드를 쓴다.
